# AI DataOps Assistant

## Overview

AI-powered incident monitoring solution for PySpark pipelines.

## Architecture

PySpark Jobs
→ n8n Webhook
→ Gemini AI Analysis
→ Incident Classification
→ Google Sheets Storage
→ Telegram Alerts

## Features

- Automated ETL failure detection
- AI-generated root cause analysis
- Incident categorization
- Historical incident storage
- Real-time alerting

## Technologies

- PySpark
- Python
- n8n
- Google Gemini
- Google Sheets
- Telegram Bot API
